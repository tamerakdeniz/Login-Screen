# 🔐 Login Screen

A simple Android login screen implementation with a splash screen.

## ⚙️ How It Works

- Shows a splash screen for 2 seconds when app launches
- Transitions smoothly to the main login screen
- Uses modern Android development practices
- Built with Kotlin and AndroidX components

## 🚀 Installation

1. Clone this repository
```bash
git clone https://github.com/tamerakdeniz/Login-Screen.git
```

2. Open the project in Android Studio

3. Sync the Gradle files

4. Run the app on an emulator or physical device

## 🛠️ Built With

- Kotlin
- Android Studio
- AndroidX Components
- Gradle Build System
